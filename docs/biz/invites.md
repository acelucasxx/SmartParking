# 邀请家人

对应 BIZ-11（PRD 5.5）。代码在 `server/member` 的 `invite` 包，接口见契约 [openapi-app.yaml](../api/openapi-app.yaml) 的 member 分组。成员列表、修改有效期、撤销、退出与到期任务见 [members.md](members.md)。

| 接口 | 权限级别 | 说明 |
| --- | --- | --- |
| `POST /api/app/devices/{deviceId}/invites` | `OWNER_ENABLED` | 发出邀请，返回分享卡片 |
| `DELETE /api/app/devices/{deviceId}/invites/{inviteId}` | `OWNER` | 撤回未接受的邀请（设备禁用时也可以） |
| `GET /api/app/invites/{token}` | 登录即可 | 打开卡片预览 |
| `POST /api/app/invites/{token}/accept` | 登录即可 | 接受邀请，返回车位卡片 |

权限级别见 [permission.md](permission.md)。接受邀请前用户与设备还没有关系，路径按 token，规则全部在这里。

## 邀请与 token

- token 为 256 位随机数，用 URL 安全 Base64 编码，共 43 个字符（PRD 9：≥ 128 位、一次性）。库里只存它的 SHA-256；明文只在创建响应和分享卡片路径 `/pages/invite/accept?token=…` 里出现。
- 卡片有效期取后台参数 `card.ttl_hours`（默认 24 小时）。邀请只能被一人接受。
- 卡片标题：`{主人昵称}邀请你使用「{设备名称}」`。昵称为空时用“微信用户”，名称为空时用“车位 {SN}”。
- 备注去首尾空白后至多 32 个字符，超长返回 10001，空串按未填写。

## 有效期

| `period.type` | 规则 |
| --- | --- |
| `PERMANENT` | 永久 |
| `RELATIVE` | `durationDays` 只能是 1、7、30，从**接受时**起算 |
| `CUSTOM` | `validFrom`、`validTo` 必填，按分钟截断；止须晚于起，且晚于当前时间。起可以早于当前时间，接受后立即生效；起在将来时，接受后到点才生效 |

不合法一律返回 30011。

## 名额

名额 = 生效中且未到期的被授权人 + 未过期的待接受邀请，上限取后台参数 `member.max_per_device`（默认 5）。

- 发出邀请时已满：30010。待接受的邀请占名额；卡片过期、被撤回即释放。名额按时间判定，不等定时任务把邀请标为过期。
- 接受时再算一次：本邀请已经占了一个名额，所以不算本邀请，只看其余占用是否已满；上限被调低时可能 30010。
- 发出邀请与接受邀请都先锁设备行，同一设备的并发请求串行执行，名额不会超。加锁顺序是先设备、后邀请，与解绑一致，不会死锁。

## 预览

`state` 告诉页面显示哪种状态，邀请失效也返回 200。token 不存在或格式不对返回 10004。

| `state` | 条件（按顺序判定） |
| --- | --- |
| `OWN_INVITE` | 看的人是主人，或就是发出邀请的人 |
| `ALREADY_MEMBER` / `ACCEPTED` | 邀请已被接受：接受人是自己 / 是别人 |
| `CANCELLED` | 已撤回或已作废（主人变更会作废全部待接受邀请） |
| `EXPIRED` | 卡片已过期，或自定义有效期已结束 |
| `CANCELLED` | 发出人已不是当前主人（兜底） |
| `ALREADY_MEMBER` | 自己已是生效中的被授权人 |
| `VALID` | 可以接受 |

## 接受

同一事务内再次校验（PRD 5.5⑧），按以下顺序：

| 顺序 | 检查 | 结果 |
| --- | --- | --- |
| 1 | token 不存在 | 10004 |
| 2 | 自己是主人或发出人 | 30016 |
| 3 | 已撤回 / 已作废；已被接受；已过期（含自定义有效期已结束） | 30014；30013（接受人是自己时 30015）；30012 |
| 4 | 发出人已不是当前主人 | 30014 |
| 5 | 设备已禁用 | 20002 |
| 6 | 自己已是生效中的被授权人 | 30015 |
| 7 | 名额 | 30010 |

- 通过后写入 `device_member`：起止按有效期规则计算；备注、授权人、来源邀请从邀请带过来。邀请置为已接受。
- 同一人在同一设备只能有一条生效授权（表上的唯一约束兜底，并发时返回 30015）。
- 旧授权已过 `validTo` 但到期任务（[members.md](members.md)）还没处理时，先把它置为已过期，不挡住新邀请。
- 事务提交后发布 `MemberGrantedEvent`，供站内消息（BIZ-15）通知主人。
- 返回被授权人视角的车位卡片；自定义有效期尚未开始时也返回，但车位列表要到开始时刻才显示该设备。

## 撤回与过期

- 只能撤回本设备待接受、未过期的邀请；已撤回的再撤回视为成功；已接受、已过期、已作废或不属于本设备返回 10004。
- 定时任务（`smartparking.invite.expire-interval`，默认 5 分钟）把过期的待接受邀请标为已过期，只是让数据与状态一致。
