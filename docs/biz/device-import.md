# 设备入库

对应 BIZ-03（PRD 5.1、7 设备入库）。代码在 `server/device`（`registry`、`imports`、`web` 包），接口见契约 [openapi-admin.yaml](../api/openapi-admin.yaml) 的 import 分组，仅超级管理员与运维可用。

## 后台守卫

守卫**失败即拒**：

- `/api/admin/**` 下除登录接口外，没有后台身份（`AdminPrincipal`）的请求一律返回 401 / 10002，角色不在允许范围内返回 403 / 10003。
- 每个后台接口都必须用 `@AdminRoles` 声明允许的角色（取契约 `x-roles`），可标在方法或类上；漏标则服务拒绝启动。
- `AdminPrincipal` 由后台会话拦截器写入（BIZ-08，见 [admin-auth.md](admin-auth.md)）。
- 集成测试用 `TestAdminIdentity`（仅测试）通过请求头模拟后台身份，省去登录。
- 单台录入、批量导入、导出印刷文件写操作日志（`DEVICE_CREATE`、`DEVICE_IMPORT`、`DEVICE_PRINT_EXPORT`）。

## 字段规则

| 字段 | 规则 |
| --- | --- |
| SN | 去空白、转大写后为 8–32 位大写字母或数字，唯一 |
| IMEI | 15 位数字，Luhn 校验，唯一 |
| 蓝牙 MAC | 可空；接受 `AA:BB:…`、`aa-bb-…` 或不分隔，统一存 `AA:BB:CC:DD:EE:FF`，唯一 |
| ICCID | 可空（仅单台录入），至多 20 位字母或数字 |
| 型号、批次 | 必填，至多 32 个字符 |

单台录入时，IMEI 不合法返回 40011，SN / IMEI / MAC 重复分别返回 40010 / 40012 / 40013，其余格式问题返回 10001。并发录入撞上唯一索引时，按索引名返回同样的错误码。

## 激活码

- 8 位，字符集去掉易混的 `0 O 1 I L`，共 31 个字符。
- 库里只存 `h1$` + HMAC-SHA256(服务端密钥, 激活码)。没有密钥时离线穷举无从下手；批量导入 5,000 台也只要毫秒级（慢哈希要几分钟）。
- 校验 `ActivateCodes.matches` 留给扫码绑定（BIZ-04）用：不区分大小写、忽略空白、恒定时间比较。
- 密钥 `smartparking.device.activate-code-key`（环境变量 `DEVICE_ACTIVATE_KEY`），至少 32 字节，缺少时拒绝启动。**换掉密钥后，已入库设备的激活码全部失效**，只能逐台重置。

单台录入时，激活码明文只出现在本次响应里。

## 批量导入

1. **同步**：上传 .xlsx 或 .csv（≤ 5 MB、≤ 5,000 行），校验格式与表头（SN、IMEI、蓝牙 MAC、型号、批次，其后可以有其他列）。格式问题直接返回 40014，不建任务；格式通过就建任务（PENDING）并立即返回，前端轮询任务详情。
2. **异步**（单线程）：在**一个事务**内逐行校验：
   - 字段格式。
   - 文件内重复：以先出现的行为准，后面的记“与第 N 行重复”。
   - 库内重复。

   校验后生成激活码、批量插入，再写入结果、失败行与加密的印刷数据。中途失败整批回滚，不会留下半批没有激活码可印的设备，修正后重新导入即可。
3. **超时清理**：处理任务的实例退出时，任务会停在 PENDING / RUNNING。每 5 分钟把创建超过 10 分钟仍未完成的任务记为失败；它的事务已回滚。即使清理恰好发生在处理过程中，事务提交前也会发现任务已不在处理中，同样回滚。

- Excel 里被存成数字的 IMEI 按原值还原，不会变成科学计数法；模板整列预设为文本格式。
- CSV 先按 UTF-8（可带 BOM）解码，不是合法 UTF-8 时按 GB18030 解码，兼容中文版 Excel 另存的 CSV。
- 失败行文件为原始五列加“失败原因”，修正后可以直接重新导入。

## 印刷文件

- ZIP 包，内含 `manifest.xlsx` 清单（序号、SN、激活码、型号、批次、二维码内容、二维码文件）与 `qr/<SN>.png`。
- **每个任务只能导出一次**：导出时加行锁，生成完整文件后，在同一事务内记录导出时间并清空暂存的激活码（`import_task.print_payload`，V9）；再次导出返回 40015。任务未完成，或没有成功入库的设备时，返回 10009。
- 响应带 `Cache-Control: no-store`。文件交付失败（如下载中断）后激活码无法找回，只能逐台重置（BIZ-10）。
- 二维码内容由 `smartparking.device.qr-url-template` 决定（必须含 `{sn}`，环境变量 `DEVICE_QR_URL_TEMPLATE`），缺少时拒绝启动。本地占位为 `https://smartparking.invalid/bind?sn={sn}`。**正式印刷前必须按小程序“扫普通链接二维码”规则（EXT-13）配置**，配错只能逐台重置。
