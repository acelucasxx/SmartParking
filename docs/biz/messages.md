# 站内消息

对应 BIZ-15（PRD 5.5–5.8、6.1 页面 13）。代码在 `server/notify` 的 `message` 包，接口见契约 [openapi-app.yaml](../api/openapi-app.yaml) 的 message 分组。

| 接口 | 说明 |
| --- | --- |
| `GET /api/app/messages` | 本人的消息，最新的在前，分页 |
| `GET /api/app/messages/unread-count` | 未读数（tabBar 角标） |
| `POST /api/app/messages/read` | `{"ids": [...]}` 标记指定消息（1–100 条），或 `{"all": true}` 全部已读 |

- 只能看到、标记本人的消息；`ids` 里他人的消息静默忽略。`ids` 与 `all` 都没给、`ids` 为空、超过 100 条或含非正数，返回 10001。
- 微信订阅消息（BIZ-18）待模板审核后接入，一期以站内消息为准。

## 写入点

各业务在事务提交后发布事件，`MessageWriters` 订阅后写入。写入失败只记错误日志，不影响业务结果。设备名称为设备的名称，未命名时为“车位 {SN}”。

| 事件 | 收件人 | 类型 | 标题 |
| --- | --- | --- | --- |
| 接受邀请（`MemberGrantedEvent`） | 被授权人 | `GRANT` | 你已获得「设备」的使用权限（正文含主人昵称与有效期） |
| | 主人 | `GRANT` | {备注或昵称}已接受邀请 |
| 修改有效期（`MemberUpdatedEvent`，只改备注不发） | 被授权人 | `GRANT` | 「设备」的使用期限已调整 |
| 撤销（`MemberEndedEvent` REVOKED） | 被授权人 | `REVOKE` | 你在「设备」的使用权限已被撤销 |
| 到期（`MemberEndedEvent` EXPIRED） | 被授权人 | `EXPIRE` | 你在「设备」的使用权限已到期 |
| 主动退出（`MemberEndedEvent` QUIT） | 主人 | `REVOKE` | {备注或昵称}已退出「设备」的授权 |
| 转让（`DeviceTransferredEvent`） | 原主人 / 新主人 / 被撤销的被授权人 | `TRANSFER` | 「设备」已转让 / 你已成为「设备」的主人 / 「设备」已转让 |
| 解绑、强制解绑（`DeviceUnboundEvent`） | 原主人 / 被撤销的被授权人 | `UNBIND` | 「设备」已解绑（强制解绑的正文提示联系客服） |
| 电机故障、离线超 24 小时（`AlarmRaisedEvent`） | 主人 | `FAULT` | 「设备」电机故障 / 「设备」已离线超过 24 小时 |

- 有效期写法：永久为“永久有效”，否则“有效期至 yyyy-MM-dd HH:mm”（东八区）；尚未开始的前面加“自 … 起”。
- 主人看到的被授权人名称：备注优先，其次昵称，昵称为空时为“微信用户”。
- 转让时，新主人原是被授权人的，只收到“你已成为主人”，不再收到“使用权限已失效”。
- 解绑会清空设备名称，消息用解绑前的名称（随事件带出）。
- 故障消息只发给主人；合并进已有告警的（30 分钟内同设备同类）不重复通知；遇阻、红外、连续超时属于单次动作问题，已在操作记录与控制页体现，不发消息。未绑定的设备没有收件人。
- 标题至多 64 个字符、正文至多 512 个字符，超长截断。
